Índice del recurso

Tocá un concepto para ir directo a su explicación.

    Todo en una web es una caja

    El secreto mejor guardado de CSS: absolutamente todo lo que ves en una página es una caja rectangular. Entender esa caja y sus cuatro capas es entender cómo se arma cualquier diseño.

    🧠 Todo es una caja

    Esta es quizás la idea más importante de todo CSS, y al principio cuesta verla: cada elemento de una página —un párrafo, una imagen, un botón, un título— es en realidad una caja rectangular. No se ven los bordes de esas cajas, pero están ahí. Entender cómo está hecha cada caja es entender cómo se arma una página entera.

    Cada caja tiene cuatro capas, como una caja de regalo: el contenido adentro, un relleno alrededor, una pared (el borde) y un espacio de aire hacia afuera. Mirá el diagrama de adentro hacia afuera →

    margin (aire exterior)
    border (la pared)
    padding (relleno interior)
    content
    (el contenido real)

    1️⃣ content

    Es el corazón de la caja: el texto, la imagen o lo que sea que va adentro. Su tamaño base lo controlan width y height (que vemos en la próxima sección).

    📦 content es la capa MÁS interna: todo lo demás (padding, border, margin) existe alrededor de ella.
    🧩 ¿Lo entendiste? · Ordená las capas
    1 · Ordenar: las capas de adentro hacia afuera

    Arrastrá las capas del modelo de caja desde la MÁS interna hasta la MÁS externa.

    2️⃣ padding

    Es el espacio entre el contenido y el borde, por dentro de la caja. Como el relleno de gomaespuma que protege un regalo. Más padding = el contenido respira más adentro de su caja.

    .tarjeta {
  padding: 20px; /* relleno en los 4 lados */
}

    📏 Antes de seguir: las unidades

    Antes de ver margin, una pausa necesaria: en CSS, un número solo no alcanza. Toda medida necesita una unidad pegada al número, si no el navegador directamente ignora la línea.

    Por ahora vas a usar casi siempre px (píxel): una unidad absoluta, fija, fácil de predecir. Más adelante existen otras unidades (%, em, rem, vw, vh) que se adaptan a la pantalla — tienen su propia sección completa más adelante (📏 Unidades). Esto es solo un adelanto para que los números de margin tengan sentido.

    /* ✅ Válida: número + unidad */
.caja {
  padding: 20px;
}

/* ❌ Inválida: falta la unidad, el navegador la ignora */
.caja {
  padding: 20;
}
    💡 Regla de oro: si escribís un número de medida en CSS, casi siempre necesita su unidad pegada, sin espacio: 20px, no 20 px ni 20.

    4️⃣ margin

    Es el espacio fuera de la caja, que la separa de las cajas vecinas. Como el espacio que dejás entre dos regalos para que no se toquen. Más margin = más distancia con los demás elementos.

    💡 La gran diferencia: padding empuja hacia ADENTRO (aleja el contenido del borde) y margin empuja hacia AFUERA (aleja la caja de sus vecinas). Confundirlos es el error #1 de quien empieza.
    .tarjeta {
  margin: 16px; /* aire alrededor de la caja */
}
    ⚠️ Cada propiedad acepta valores por lado: padding: 10px 20px; es 10px arriba/abajo y 20px a los lados. Y padding-top, margin-left, etc., controlan un solo lado.

    🎯 Centrar con margin: 0 auto;

    Casi nunca queremos que el contenido principal ocupe toda la ventana en pantallas grandes: limitarlo y centrarlo mejora la lectura. La receta clásica para centrar un elemento de bloque que ya tiene un ancho definido:

    1Asegurate de que el elemento sea display: block (la mayoría de los contenedores ya lo son).
    2Dale un ancho explícito con width o max-width.
    3Aplicá margin-left: auto; y margin-right: auto; — o el atajo margin: 0 auto;
    ⚠️ Este truco no funciona sin un ancho definido. Si el elemento no tiene width o max-width, ya ocupa todo el ancho disponible y no hay "espacio sobrante" para repartir.
    .contenedor {
  width: 600px;
  margin: 0 auto; /* 0 arriba/abajo, auto a los lados */
}
    💡 margin: 0 auto; le dice al navegador: "repartí el espacio sobrante en partes iguales a la izquierda y a la derecha". Por eso el elemento queda centrado horizontalmente.

    Controlar el tamaño de las cajas
    
  
    Una vez que sabés que todo es una caja, el siguiente paso es decidir cuánto mide. Y el truco no es fijar tamaños exactos, sino que se adapten a cada pantalla.
    

    
    
    
    
      
    
      
      
      
      
    
    
    
    
    
    
    
      
    
        
    📐 width y height
    
        
    
        
    
          
    Por defecto, las cajas se estiran o se encogen según su contenido. Pero muchas veces querés decidir vos el tamaño: una imagen que no supere cierto ancho, una columna fija, una tarjeta que no se deforme. Para eso están width, height y sus versiones "máximas".
    
          
    width fija el ancho del contenido y height el alto. Pensalos como decirle a la caja "vas a medir exactamente esto".
    
        
    
        
    

    .banner {
  width: 300px;
  height: 150px;
}

    🚧 max-width y max-height
    
        
    
        
    
          
    Estas son las más útiles para diseño responsivo (que se adapta a cualquier pantalla). max-width dice "podés ser más chica, pero nunca más ancha que esto". Así una imagen se achica en el celular pero no se desborda gigante en la compu.
    
          
    💡 max-width: 100% en las imágenes es uno de los trucos más usados de la web: garantiza que ninguna foto rompa el diseño en pantallas chicas.
    
        
    
        
    

    img {
  max-width: 100%; /* nunca más ancha que su contenedor */
}
.contenido {
  max-width: 700px; /* lectura cómoda en pantallas grandes */
}

    Los bordes son la "pared" visible de la caja.     ¿Píxeles o porcentajes? Las unidades de CSS
    
  
    No es lo mismo medir en píxeles fijos que en unidades que se adaptan. Elegir bien la unidad es la diferencia entre un sitio rígido y uno que se ve bien en cualquier dispositivo.
    

    
    
    
    
      
    
      
      
      
      
    
    
    
    
    
    
    
      
    
        
    📏 Absolutas: px
    
        
    
        
    
          
    Cuando escribís font-size: 16px o width: 50%, ese px o ese % es una unidad de medida. Hay dos grandes familias: las absolutas (siempre miden lo mismo) y las relativas (miden en relación a algo más).
    
          
    El píxel (px) es la unidad absoluta más usada: un tamaño fijo, exacto, que no cambia. Es predecible y fácil de entender — ideal para bordes finos o detalles que deben medir siempre lo mismo.
    
        
    
        
    

    .borde { border: 2px solid black; }
h1 { font-size: 32px; }
    
        
    

    
        🧩 ¿Lo entendiste? · De absoluta a más relativa
        
    

    1 · Ordenar: de absoluta a "más relativa"
    
        
    Ordená estas unidades desde la ABSOLUTA (fija) hacia las que dependen de cosas cada vez más grandes.
    
        
    
        
        
    
      
        
    
      
    

    
        🎬 Video: Unidades de medida (min 01:16:47)
        
    
          
    
        
    
      
    
        
    
      
    

      
    
        
    🌊 Relativas: em, rem, %, vw, vh
    
        
    
        
    
          
    Las unidades relativas se calculan respecto a otra cosa, y por eso son las reinas del diseño adaptable.
    
          
    💡 rem vs em: rem siempre mira a la página (predecible), em mira al elemento (puede acumularse y volverse confuso). Para tamaños de texto, rem suele ser la opción más segura.
    
          
    💡 vw y vh son geniales para secciones a pantalla completa: height: 100vh hace que un bloque ocupe exactamente toda la altura visible, sin importar el dispositivo.
    
        
    
        
    

    
    
    UnidadRelativa a…Ejemplo
    
    
      
    %El tamaño del elemento padrewidth: 50% = la mitad del contenedor
    
      
    emEl tamaño de fuente del elemento2em = el doble de su letra
    
      
    remEl tamaño de fuente de la raíz (la página)1.5rem = 1,5× la base
    
      
    vwEl ancho de la ventana (viewport width)100vw = todo el ancho de pantalla
    
      
    vhEl alto de la ventana (viewport height)100vh = toda la altura de pantalla

    Relativa al elemento padre → 
    
          
    Relativa al ancho de la ventana → 
    
          
    Relativa a la fuente de la página →

    display: cómo se comportan las cajas
    
  
    La propiedad display decide la regla de juego de cada caja: si ocupa toda la fila, si se pone al lado de otras, o si arma una grilla completa. Es una de las propiedades más poderosas de CSS.
    

    
    
    
    
      
    
      
      
      
      
      
      
      
      
    
    
    
    
    
    
    
      
    
        
    🧱 block — ocupa toda la fila
    
        
    
        
    
          
    Hasta ahora cada caja vivía en su lugar. La propiedad display es la que decide cómo se acomodan las cajas entre sí: si se apilan una debajo de otra, si van en fila, si forman columnas…
    
          
    Un elemento block ocupa todo el ancho disponible y empuja al siguiente hacia abajo. Por defecto son block los <div>, <p>, <h1>… Se apilan como ladrillos, uno sobre otro.
    
        
    
        
    
          
    🧱 block = una fila entera para cada caja, apiladas de arriba a abajo.
    
        
    

    
        🎬 Video: Display & Visibility (min 02:28:28)
        
    
          
    
        
    
      
    
        
    
      
    

      
    
        
    ↔️ inline — solo lo que ocupa
    
        
    
        
    
          
    Un elemento inline ocupa solo el ancho de su contenido y deja que otros se pongan al lado, en la misma línea. Por defecto son inline los <a>, <span>, <strong>…
    
          
    No se les puede fijar width ni height: siempre miden lo que mide su contenido.
    
        
    
        
    
          
    ↔️ inline = solo el espacio justo, y comparte la línea con otros elementos.
    
        
    
        
    
      
    

      
    
        
    🧩 inline-block — lo mejor de los dos
    
        
    
        
    
          
    Se pone al lado de otros (como inline) pero sí acepta width, height, padding y margin (como block). Útil para botones o tarjetas que van en fila pero necesitan tamaño propio.
    
        
    
        
    
          
    🧩 inline-block = fila + tamaño propio. El equilibrio entre block e inline.
    
        
    
        
    
      
    

      
    
        
    🚫 none — desaparece
    
        
    
        
    
          
    display: none hace que el elemento deje de existir visualmente: no ocupa espacio, como si no estuviera. Se usa muchísimo para mostrar/ocultar cosas (menús desplegables, mensajes).
    
        
    
        
    
          
    🚫 none = invisible Y sin espacio reservado. No confundir con solo "ocultar visualmente".
    
        
    

    
        🧩 ¿Lo entendiste? · De "apila" a "cuadrícula"
        
    

    1 · Ordenar: de "apila" a "cuadrícula"
    
        
    Ordená estos valores de display desde el que apila en columna simple hasta el que arma cuadrículas completas.
    
        
    
        
        
    
      
        
    
      
    
        
    
      
    

      
    
        
    🧵 flex — filas y columnas flexibles
    
        
    
        
    
          
    display: flex convierte un contenedor en flexible: sus hijos se alinean en fila (o columna) y se reparten el espacio de forma inteligente. Es la herramienta moderna para alinear y centrar — adiós a los trucos viejos.
    
        
    
        
    

    .barra {
  display: flex;
  gap: 10px; /* espacio entre los hijos */
}
    
        
    

    
        🧩 ¿Lo entendiste? · Cada valor con su comportamiento

    🔳 grid — cuadrículas
    
        
    
        
    
          
    display: grid arma una cuadrícula de filas y columnas. Perfecto para galerías, tableros y layouts completos de página. Definís cuántas columnas querés y los hijos se acomodan solos.
    
          
    💡 Regla práctica: flex para alinear cosas en UNA dirección (una fila o una columna); grid cuando necesitás filas Y columnas a la vez.
    
        
    
        
    

    .galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 3 columnas iguales */
  gap: 12px;
}

    float: el texto que rodea
    
  
    Antes de las herramientas modernas, float era la forma de hacer que el texto envolviera una imagen, como en las revistas. Sigue siendo útil saber cómo funciona.
    

    
    
    
    
      
    
      
      
      
      
    
    
    
    
    
    
    
      
    
        
    🌊 float: left y float: right
    
        
    
        
    
          
    La propiedad float nació para algo muy concreto: hacer que el texto envuelva una imagen, como en las revistas y los diarios. "Flotás" una imagen a la izquierda o a la derecha, y el texto se acomoda alrededor.
    
          
    Hoy para armar layouts usamos flex y grid, pero float sigue siendo útil para ese efecto clásico — y vas a encontrarlo en mucho código existente.
    
        
    
        
    

    .foto {
  float: left; /* la foto va a la izquierda, el texto la rodea */
  margin: 0 15px 10px 0; /* aire para que el texto no se pegue */
}
    
        
    

    
        🧩 ¿Lo entendiste? · Los pasos para flotar bien una imagen
        
    

    1 · Ordenar: los pasos para flotar bien una imagen
    
        
    Ordená los pasos para que una imagen flote y el contenedor no colapse.
    
        
    
        
        
    
      
        
    
      
    

    
        🧩 ¿Lo entendiste? · Cada regla con su función
        
    

    2 · Arrastrar y soltar: cada regla con su función
    
        
    
        
    
          
    Foto a la izquierda, texto la rodea → 
    
          
    Contener los floats (limpieza) → 
    
          
    Quitar la flotación → 
    
        
    
        
        
    
      
        
    
      
    

    
        🎬 Video: Float (min 02:52:53)
        
    
          
    
        
    
      
    
        
    
      
    

      
    
        
    🧹 El problema: el contenedor “colapsa”
    
        
    
        
    
          
    Antes del truco puntual, conviene conocer la propiedad en general: overflow le dice al navegador qué hacer cuando el contenido de una caja no entra en ella. Sus valores más comunes son visible (el contenido se desborda igual, es el valor por defecto), hidden (lo que no entra se recorta y desaparece), scroll (agrega barras de desplazamiento siempre) y auto (agrega barras de desplazamiento solo si hacen falta).
    
          
    Cuando todos los hijos de una caja están flotados, la caja padre pierde su altura y parece vacía — un clásico dolor de cabeza.
    
          
    La solución más simple es ponerle al contenedor overflow: hidden, que lo obliga a "contener" a sus hijos flotados: es un uso puntual de overflow, aprovechando que "recortar lo que se desborda" también sirve para contener floats.
    
          
    ⚠️ Si después de usar float ves que el fondo o el borde del contenedor no rodean a los elementos, casi seguro te falta la "limpieza": overflow: hidden en el padre lo resuelve en la mayoría de los casos.
    
        
    
        
    

    .contenedor {
  overflow: hidden; /* técnica de limpieza: contiene los floats */
}
    
        
    

    
        🧩 ¿Lo entendiste? · Completá float y limpieza
        
    

    3 · Completar: float y limpieza
    
        
    /* Imagen flotada a la derecha */
.foto { : ; }

/* Limpieza: que el contenedor contenga los floats */
.caja { overflow: ; }

    position: ubicar cajas con precisión
    
  
    A veces no alcanza con el flujo normal: querés un elemento en una esquina exacta, o un menú que te siga al hacer scroll. Para eso existe position.
    

    
    
    
    
      
    
      
      
      
      
      
      
      
      
    
    
    
    
    
    
    
      
    
        
    📌 static — la posición por defecto
    
        
    
        
    
          
    La propiedad position te da control fino sobre dónde se ubica exactamente una caja. Hasta ahora las cajas iban en el flujo natural (una tras otra); con position podés moverlas, superponerlas o fijarlas en pantalla.
    
          
    static es el valor normal: la caja va donde le toca en el flujo, sin moverse. Todas las cajas son static hasta que les decís otra cosa.
    
        
    
        
    
          
    📌 static = el comportamiento por defecto. Ningún top/left/right/bottom tiene efecto.
    
        
    
        
    
      
    

      
    
        
    ↕️ relative — me corro desde mi lugar
    
        
    
        
    
          
    La caja se ubica respecto a su propia posición original. Con top, left, etc., la empujás desde donde estaba, pero su hueco original se mantiene reservado.
    
        
    
        
    

    .etiqueta {
  position: relative;
  top: 10px; /* 10px más abajo que su lugar normal */
}
    
        
    

    
        🧩 ¿Lo entendiste? · Del más "quieto" al más "fijo"
        
    

    1 · Ordenar: del más "quieto" al más "fijo a pantalla"
    
        
    Ordená los valores de position: del que no se mueve nada, al que queda clavado a la ventana.
    
        
    
        
        
    
      
        
    
      
    
        
    
      
    

      
    
        
    🎯 absolute — respecto a un ancestro
    
        
    
        
    
          
    La caja sale del flujo (deja de reservar su lugar) y se posiciona respecto al ancestro posicionado más cercano. Sirve para colocar algo en una esquina exacta, como un globo de "nuevo" sobre una tarjeta.
    
          
    💡 Truco clásico: poné position: relative en el contenedor y position: absolute en el hijo. Así el hijo se ubica respecto al contenedor, no respecto a toda la página.
    
        
    
        
    
          
    🎯 absolute necesita un ancestro con position: relative para no ubicarse respecto a toda la página.
    
        
    

    
        🧩 ¿Lo entendiste? · Cada valor con su referencia
        
    

    2 · Arrastrar y soltar: cada valor con su referencia
    
        
    
        
    
          
    Posición normal por defecto → 
    
          
    Se corre desde su lugar original → 
    
          
    Clavado a la ventana al hacer scroll → 
    
          
    Menú que se pega al bajar → 
    
        
    
        
        
    
      
        
    
      
    
        
    
      
    

      
    
        
    📍 fixed — me clavo a la pantalla
    
        
    
        
    
          
    La caja se fija respecto a la ventana del navegador y no se mueve aunque hagas scroll. Es lo que usan los botones flotantes de "subir" o de chat que siempre ves en una esquina.
    
        
    
        
    
          
    📍 fixed = clavado a la ventana, no a la página. Por eso siempre se ve, aunque bajes el scroll.
    
        
    

    
        🧩 ¿Lo entendiste? · Completá el posicionamiento
        
    

    3 · Completar: posicionamiento
    
        
    /* Menú que se pega arriba al hacer scroll */
.menu { position: ; top: 0; }

/* Botón flotante clavado a la ventana */
.flotante { position: ; }

/* Contenedor base para posicionar un hijo absolute */
.tarjeta { position: ; }
    
        
        
    
      
        
    
      
    
        
    
      
    

      
    
        
    🧷 sticky — pegajoso para menús
    
        
    
        
    
          
    Mezcla lo mejor: la caja se comporta normal hasta que llegás a cierto punto al hacer scroll, y ahí se "pega" y queda fija. Es la técnica detrás de los menús que acompañan mientras bajás por la página.
    
        
    
        
    

    .menu {
  position: sticky;
  top: 0; /* se pega al borde superior al hacer scroll */
}
    

    
    
    ValorRespecto a…Uso típico
    
    
      
    staticEl flujo normalEl comportamiento por defecto
    
      
    relativeSu propia posición originalPequeños ajustes; base para absolute
    
      
    absoluteSu ancestro posicionadoGlobos, etiquetas, esquinas exactas
    
      
    fixedLa ventana del navegadorBotones flotantes que no se mueven
    
      
    stickyEl scroll (mezcla)Menús que acompañan al bajar
    
        
  
    
        
    

    
        ✅ Repaso rápido · Opción múltiple
        
    

    4 · Opción múltiple: posicionamiento
    
        
    

        
    
      
    
        
    
      
    

      
    
        
    🗂️ z-index — quién queda arriba
    
        
    
        
    
          
    Cuando dos cajas posicionadas (con relative, absolute, fixed o sticky) se superponen, alguna queda arriba y tapa a la otra. z-index es el número que decide ese orden: cuanto más alto, más adelante queda el elemento.
    
          
    ⚠️ z-index solo funciona en elementos posicionados: si el elemento tiene position: static (el valor por defecto), z-index no tiene ningún efecto.
    
        
    
        
    

    .globo {
  position: absolute;
  z-index: 10; /* queda por encima de las cajas con z-index menor */
}
    
          
    🗂️ z-index más alto = más al frente. Solo cuenta en elementos con position distinto de static.
